# Tabularium

**A Visual Database Simulator**

Tabularium is a desktop-based visual database simulator designed to demonstrate how data organization, database operations, and information management can be represented through an interactive graphical user interface.

Inspired by the historical Roman *Tabularium*, a public records archive, this project aims to bring data management to life through visual representation, interactive components, and an accessible desktop experience.

---

## About the Project

Tabularium is developed using **Java** and **JavaFX**, with a particular focus on exploring desktop application development and graphical user interface design.

### The project serves two purposes:

- **Practical Application:** Develop a visual environment for representing and managing database-related information, including records and quantity tracking.
- **Learning Experience:** Explore JavaFX and its capabilities in building desktop applications, including layouts, components, event handling, window management, and visual customization.
